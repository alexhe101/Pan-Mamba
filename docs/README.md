# Project page

A dependency-free static research site. Preview from the repository root:

```bash
python -m http.server 8000 --directory docs
```

The page uses an original explanatory SVG, not simulated satellite results. Source links and quantitative results (where available) are credited in the page.

Once reviewed and merged, enable GitHub Pages at https://github.com/alexhe101/Pan-Mamba/settings/pages using **Deploy from a branch → main → /docs**. Expected public URL: https://alexhe101.github.io/Pan-Mamba/. The page is not yet published by this branch.
